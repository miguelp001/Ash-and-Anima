# Ash and Anima

A Unity project built with the Universal Render Pipeline (URP).

## Project Details

- **Unity Version:** 6000.6.4f1 (Unity 6)
- **Render Pipeline:** Universal Render Pipeline (URP 17.7.0)
- **Platform:** Windows / Desktop
- **Input System:** Unity Input System (com.unity.inputsystem 1.20.0)
- **Version Control:** Git with Git LFS (Large File Storage) for binary assets

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone git@github.com:miguelp001/Ash-and-Anima.git
   cd Ash-and-Anima
   git lfs pull
   ```

2. **Open in Unity:**
   - Launch **Unity Hub**.
   - Add this project directory.
   - Open using **Unity 6000.6.4f1** (or compatible Unity 6 release).

## Structure

- `Assets/` - Game assets, scripts, materials, and scenes.
- `Packages/` - Package manifests and dependencies.
- `ProjectSettings/` - Unity project configuration settings.
